# Prompt / Instrucciones para Generación de Imágenes Educativas desde PowerPoint

A partir del archivo PowerPoint **“[NOMBRE DEL ARCHIVO].pptx”**, revisa todas sus diapositivas y crea una imagen educativa, dinámica y entretenida para cada una, incorporando dentro de la imagen el contenido esencial de la diapositiva.

---

### 📋 Requisitos:

1. **Orden:** Mantener el orden original de las diapositivas.
2. **Formato:** Crear imágenes en formato **16:9**, adecuadas para una presentación.
3. **Estilo visual:** Usar un estilo visual moderno, educativo y profesional, relacionado con **redes computacionales**.
4. **Síntesis:** Sintetizar el contenido sin perder los conceptos principales.
5. **Legibilidad:** Incorporar textos grandes, claros y legibles dentro de cada imagen.
6. **Elementos visuales:** Utilizar colores atractivos, iconos y metáforas visuales que faciliten el aprendizaje.
7. **Pie de página obligatorio (en todas las imágenes):**
   - `"Mario Augusto Villanueva Alveal"`
   - `"ENSA - Cisco Networking Academy"`
8. **Logo:** [Incluir / omitir] el logo institucional proporcionado.
9. **Sin elementos extra:** No agregar marcas de agua ni textos que no correspondan al contenido.
10. **Filtro de contenido:** Omitir las diapositivas que sean únicamente guías del instructor, planificación o material administrativo, salvo que se solicite lo contrario.

---

### 📁 Organización y Archivos:

* **Carpeta de destino:** Guardar las imágenes en una carpeta llamada **“[NOMBRE DEL MÓDULO]”**, dentro de:
  `[RUTA DE DESTINO]`
* **Nomenclatura:** Nombrar cada imagen según el número de diapositiva, por ejemplo:
  `01.png`, `02.png`, `03.png`, etc.

---

### 🔄 Flujo de Trabajo:

1. **Muestra inicial:** Generar primero una pequeña muestra para revisar el estilo visual.
2. **Aprobación:** Después de mi aprobación, continuar con el resto de las diapositivas en grupos.
3. **Reporte:** Al finalizar cada grupo, informar qué imágenes fueron creadas y guardadas.
